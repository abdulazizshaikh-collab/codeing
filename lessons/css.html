Lesson 2

Making it look good

CSS decides how HTML looks: colour, size, spacing, and where things sit. It is a list of rules, and every rule answers “which thing, what property, what value?”

A rule has a selector and a body

p {
  color: #2f6fed;
  font-size: 18px;
}

Read it as: for every paragraph, make the text blue and the size 18 pixels. The part before the braces chooses elements; the inside describes the change.

Selectors pick the elements

  • p — every paragraph.
  • .card — everything with class="card".
  • #main — the one element with id="main".
  • .card a — links inside a card.

Boxes have edges

Every element is a box with content in the middle, then padding, a border, and margin outside. Padding pushes the content away from its own border; margin pushes neighbouring boxes away. 

.card {
  padding: 1.25rem;
  border: 1px solid #e4e0d6;
  border-radius: 14px;
  margin-bottom: 1rem;
}

Layout with one line

display: flex is the fastest way to put things side by side, and display: grid with auto-fit lets cards wrap on their own as the screen narrows. 

.card-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(15rem, 1fr));
  gap: 1rem;
}

Try it

Open assets/style.css and find the --accent variable near the top. Change its value to any hex colour you like and save — links, buttons and borders that use it will all follow.
