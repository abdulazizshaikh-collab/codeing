Lesson 3

Making it do something

JavaScript is the behaviour of a page. It can read what the user did, remember a value, and change the page in response — without a reload.

A value and a name

const gives a name to a value you will not reassign; let makes a name you can change later. 

const lesson = 'JavaScript';
let score = 0;
score = score + 1;

Finding something on the page

document.querySelector takes a CSS selector — the same syntax you learned in lesson 2 — and hands back the first matching element. 

const feedback = document.querySelector('.quiz-feedback');

Reacting to a click

The function you pass to addEventListener runs every time the event happens. This is exactly how the quizzes on these pages work. 

button.addEventListener('click', () => {
  feedback.textContent = 'You clicked it.';
});

Changing what the user sees

  • element.textContent — replace the text inside an element.
  • element.classList.add('is-correct') — attach a CSS class.
  • element.setAttribute('aria-expanded', 'true') — update an attribute.

Because you are only changing classes and text, all the real styling still lives in CSS — the JavaScript just decides when it applies.
